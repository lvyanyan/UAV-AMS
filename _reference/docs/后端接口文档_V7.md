## 1. 全局约定

### 1.1 坐标规范

| 原则 | 说明 |
|------|------|
| 坐标系 | 所有 `longitude` / `latitude` 均为 **WGS84 (EPSG:4326)** 绝对经纬度 |
| 无需偏移 | 数据库存储的 GPS 坐标直接输出，**不做任何相对中心点减法** |
| 高度 | 所有 `height` 字段单位为**米**，相对于椭球体表面 |
| 时间戳 | `timems` 为 **Unix 毫秒**（绝对时间），起点建议 `1779350400000`（2026-05-21T08:00:00+08:00） |
| 时间秒 | startTime/endTime 为**相对于 timeOriginMs 的秒偏移**（整型） |

### 1.2 全局参数

| 参数 | 默认值 | 说明 |
|------|:------|------|
| 无人机总数 | 300 | 全量规模 |
| 总时长 | 3600 秒 | 默认时间范围 |
| 帧间隔 | 2 秒 | 轨迹采样间隔 |
| 目标包大小 | ~3 MB | 动态分包依据 |
| 单帧字节估算 | 300 B | 用于估算包体大小 |
| 坐标类型 | **WGS84 绝对经纬度** | 不对任何中心点做偏移 |

### 1.3 通用响应格式

```json
{
  "code": 0,
  "message": "ok",
  "data": { ... }
}
```

错误码：

| code | 含义 |
|-----:|------|
| 0 | 成功 |
| 4001 | 缺少 planId 参数 |
| 4002 | 包索引超出范围 |
| 4004 | planId 无效或已过期 |

## 3. planId 生命周期

### 3.1 原理

`POST /api/init` 为每次请求创建一份临时存储（plan），返回 UUID 作为 `planId`。后续 `GET /api/drone/packet/{idx}?planId=xxx` 通过 planId 查找数据范围生成分包。

### 3.2 前端释放时机

| 时机 | 方式 |
|------|------|
| 旧 plan 被替换 | `fetchInit` 内部自动对旧 planId 发 DELETE |
| 标签页关闭 | `beforeunload` → `fetch(..., { keepalive: true })` |
| 组件卸载 | Vue `onUnmounted` → `fetch` DELETE |

### 3.3 后端兜底与活跃性检查

**建议**：plan 上限 **20 个**，TTL **30 分钟**。生产环境建议根据实际并发用户数调整（公式：`上限 = 用户数 × 3`，TTL 建议不超过 1 小时）。

**活跃性检查（重要）**：每次 `GET /api/drone/packet/{idx}?planId=xxx` 访问时，应**刷新该 plan 的 TTL**（即 `touch` 操作，将 `last_access_at` 更新为当前时间）。这样正在活跃播放的 plan 不会因 TTL 过期而被清理。

| 机制 | 说明 |
|------|------|
| 最大 plan 上限 | 保留最近 **20** 个（建议 `用户数×3`），超出 FIFO 淘汰 |
| TTL 过期 | 每个 plan 设置 **30 分钟** TTL，定期清理 |
| **活跃延长** | packet 接口每次访问时刷新 `last_access_at`，延长该 plan 的 TTL |
| DELETE 立即释放 | 收到 DELETE 后立刻清理 plan 及关联缓存 |

### 3.4 生产建议

```
plan 上限 = max(20, 预估并发用户数 × 3)
TTL      = 30 分钟（用户离开页面后 30 分钟自动回收）
清理策略 = 惰性清理 (每次新 init 时扫一遍) + 定时任务 (每 5 分钟)
```

### 6.9 后端实现要点

1. **planId 查表**：`planEntry = planStore.get(planId)`，不存在返回 4004
2. **活跃性 touch**：每次访问更新 `planEntry.last_access_at = now()`，防止活跃 plan 被 TTL 淘汰

4. **包内过滤**：所有时效数据按时间窗交集下发
5. **缓存**：全量包可缓存（key=`planId:idx`），筛选包不缓存
6. ~~筛选后过滤~~：**⚠️ 预留，本次 filterDroneIds 始终为 null，不过滤**

import uuid, time
from fastapi import FastAPI, Query, Body
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

TIME_ORIGIN_MS = 1779350400000
DEFAULT_TOTAL_DURATION = 3600
FRAME_INTERVAL = 2
TARGET_PACKET_BYTES = 3_000_000
BYTES_PER_FRAME = 300
BYTES_OVERHEAD = 50000
VALID_PACKET_DURATIONS = [10, 15, 20, 30, 60, 120, 180, 300, 600]
PLAN_MAX = 20          # 建议：预估并发用户数 × 3
PLAN_TTL = 1800        # 30 分钟

plan_store = {}
packet_cache = {}

# ⚠️ 预留数据类，本次不启用 ——————————————————————
# class InitFilters(BaseModel):
#     keyword: Optional[str] = None
#     missionTypes: Optional[List[str]] = None
#     hasAlarm: Optional[bool] = None
#     alarmTypes: Optional[List[str]] = None
#     alarmLevels: Optional[List[str]] = None
# ⚠️ 预留结束 ————————————————————————————————————

class InitRequest(BaseModel):
    timeStart: Optional[int] = None
    timeEnd: Optional[int] = None
    # ⚠️ 预留字段，本次不启用
    # filters: Optional[InitFilters] = None


def calc_packet_plan(total_sec: int, drone_count: int) -> dict:
    total_frames = drone_count * (total_sec / FRAME_INTERVAL)
    est_bytes = total_frames * BYTES_PER_FRAME
    ideal_pkts = max(1, int(est_bytes / TARGET_PACKET_BYTES + 0.5))
    ideal_dur = total_sec / ideal_pkts
    pkt_dur = min(VALID_PACKET_DURATIONS, key=lambda d: abs(d - ideal_dur))
    total_pkts = (total_sec + pkt_dur - 1) // pkt_dur
    return {
        "totalDuration": total_sec,
        "packetDuration": pkt_dur,
        "totalPackets": total_pkts,
        "droneCount": drone_count,
        "frameInterval": FRAME_INTERVAL,
        "timeOriginMs": TIME_ORIGIN_MS,
        "estimatedBytesPerPacket": int(est_bytes / total_pkts) + BYTES_OVERHEAD
    }


def release_plan(pid: str):
    plan_store.pop(pid, None)
    for k in list(packet_cache):
        if k.startswith(pid):
            del packet_cache[k]


def touch_plan(pid: str):
    """活跃性检查：每次 packet 访问时刷新 last_access_at"""
    entry = plan_store.get(pid)
    if entry:
        entry["last_access_at"] = time.time()


def cleanup():
    """清理过期 + 超量 plan。活跃 plan 不淘汰"""
    now = time.time()
    for pid in list(plan_store):
        entry = plan_store[pid]
        age = now - entry.get("last_access_at", now)
        if age > PLAN_TTL:
            release_plan(pid)
    # FIFO 淘汰最旧的（按 last_access_at）
    while len(plan_store) > PLAN_MAX:
        oldest = min(plan_store, key=lambda k: plan_store[k].get("last_access_at", 0))
        release_plan(oldest)


# ① POST /api/init
@app.post("/api/init")
async def init(req: InitRequest):
    time_start_ms = req.timeStart or TIME_ORIGIN_MS
    time_end_ms = req.timeEnd or (TIME_ORIGIN_MS + DEFAULT_TOTAL_DURATION * 1000)
    total_sec = (time_end_ms - time_start_ms + 999) // 1000
    t0_sec = (time_start_ms - TIME_ORIGIN_MS) // 1000
    t1_sec = (time_end_ms - TIME_ORIGIN_MS) // 1000

    # ★ 本次始终全量，忽略 req.filters
    all_drones = get_all_drones()

    # ★ 始终创建 plan
    plan = calc_packet_plan(total_sec, len(all_drones))
    plan_id = str(uuid.uuid4())
    now = time.time()

    plan_store[plan_id] = {
        "plan": plan,
        "filterDroneIds": None,    # ⚠️ 预留：筛选时存 droneId 列表
        "droneMetas": all_drones,
        "timeStartSec": t0_sec,
        "timeEndSec": t1_sec,
        "created_at": now,
        "last_access_at": now      # ★ 活跃性时间戳
    }
    cleanup()

    result = {
        "planId": plan_id,
        "plan": plan,
        "drones": [d.to_meta() for d in all_drones]
        # ⚠️ alarmTypes / alarms 预留，本次不返回
    }

    return {"code": 0, "message": "ok", "data": result}

@app.get("/api/drone/packet/{idx}")
async def drone_packet(idx: int, planId: str = Query(...)):
    entry = plan_store.get(planId)
    if not entry:
        return {"code": 4004, "message": "Invalid or expired planId"}

    # ★ 活跃性 touch：每次访问刷新 TTL
    touch_plan(planId)

    plan = entry["plan"]
    filter_ids = entry["filterDroneIds"]   # ⚠️ 本次为 None
    t0 = entry["timeStartSec"]

    if idx < 0 or idx >= plan["totalPackets"]:
        return {"code": 4002,
                "message": f"Packet index out of range: 0~{plan['totalPackets'] - 1}"}

    start_sec = t0 + idx * plan["packetDuration"]
    end_sec = min(start_sec + plan["packetDuration"], t0 + plan["totalDuration"])

    return {"code": 0, "message": "ok", "data": {
        "packetIndex": idx,
        "startTime": start_sec - t0,
        "endTime": end_sec - t0,
        "data_list": get_track_frames(entry["droneMetas"], start_sec, end_sec),
        "alarms": get_alarms_in_range(start_sec, end_sec, filter_ids),
        "time_airspaces": get_time_airspaces(start_sec, end_sec),
        "time_routes": get_time_routes(start_sec, end_sec),
        "weather": get_weather(start_sec, end_sec),
        "flight_plans": get_flight_plans_in_range(start_sec, end_sec, filter_ids)
    }}
