# 无人机全空域管控数字孪生系统 🛸

基于 **Vue 3 + CesiumJS 1.104** 构建。支持万架级无人机渲染、倍速回放、多源数据融合。

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🛸 **海量渲染** | BillboardCollection GPU 实例化，万架 60fps |
| ⏱️ **倍速回放** | 0.5x~10x，时间轴任意跳转 |
| 🗺️ **多图层** | 无人机/网格/热力图/航路/航迹/空域分区独立开关 |
| 🖱️ **点选交互** | 点击无人机查看信息 |
| 🏗️ **3D Tiles** | 支持 b3dm 空域数据 |

## 🚀 快速启动

```bash
npm install
npm run dev
```

## 🏗️ 技术栈

| 领域 | 方案 |
|------|------|
| 前端框架 | Vue 3 |
| 3D 引擎 | CesiumJS 1.104 |
| 海量图标 | BillboardCollection |
| 构建工具 | Vite 5 |
